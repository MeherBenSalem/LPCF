# LPCF 2.0.0: Chat, Nametags & Bubbles

LPCF is now your LuckPerms rank everywhere players look: in chat, **above their heads** and **in the tab list**,
with chat bubbles, mentions, clickable links and hover cards. One jar for Paper, Purpur and Folia, Minecraft 1.20.1
to 26.3.

## New

- **Text-display nametags**: full MiniMessage (gradients, hex) and several lines above every player's head, from
  `nametags.lines`. They follow teleports, deaths and dimension changes, refresh when LuckPerms changes, hide while
  the player is invisible, in spectator mode, dead or vanished, and dim while sneaking. The vanilla name is hidden
  underneath. **They work on Folia**, which has no scoreboard teams: there the tag rides the player, which hides the
  vanilla name as well. On Paper and Purpur nothing rides the player, so `/home`, `/spawn` and `/tpa` plugins keep
  working.
- **Chat bubbles**: public chat floats above the speaker for 3 to 10 seconds. `/lpcf bubbles [on|off]` per player.
- **Hover card and click-to-message** on names in chat (`name-hover`).
- **Mentions**: `@name` or a bare name is highlighted; the mentioned player hears a sound and gets an action-bar notice.
- **Clickable links**, **emoji shortcuts** (`<3`, `:star:`, `:check:`, `:x:`, `:shrug:`, `:tableflip:`, add your own).
- **Tab list**: header and footer with `{online}`, `{max-players}`, `{ping}` and placeholders; sorted by LuckPerms
  group weight.
- **Join, first-join and quit messages**, per group.
- **World formats** (`world-formats`), after group and track formats.
- **`/lpcf debug [player]`** shows group, weight, prefix, suffix, meta colours, which chat format applies and why,
  the nametag mode and the integrations. **`/lpcf preview <message>`** shows your own chat line (from the console:
  `/lpcf preview <player> <message>`, with the line's JSON).
- `{group}` placeholder everywhere; `[ITEM]` now shows the item in the viewer's language with its amount.

## Fixed

- **1.20.1 and 1.21.x servers can run LPCF again.** 1.2.4 and 1.2.5 were compiled for Java 25 and could only load on
  26.x. 2.0 is Java 17 bytecode built against the 1.20.1 API.
- **Chat injection**: the player's message used to be pasted into the format before PlaceholderAPI and MiniMessage
  ran, so players could make the server expand `%placeholders%` in public chat. The message is now inserted as a
  component after parsing and never reaches PlaceholderAPI.
- `lpcf.colorcodes` allowed every MiniMessage tag, including click and hover events. It now allows colours,
  decorations, gradients and rainbow only.
- Players without `lpcf.colorcodes` lost anything between `<` and `>` (so "<3" disappeared). Their text is now shown
  exactly as typed.
- Folia: above-head nametags were impossible since 1.2.5; they are back, as text displays.

## Changed

- **The plugin is now called `LPCF`** (it was `LuckPermsChatFormatterFolia`). The jar is `LPCF-2.0.0.jar` and the data
  folder `plugins/LPCF`: your old folder is moved automatically on first start. **Delete the old
  `LuckPermsChatFormatterFolia-*.jar`.** The `/lpcf` command and every `lpcf.*` permission are unchanged.
- `config.yml` gains `config-version: 2` and the new sections, with comments. Your values are kept and the old file
  is saved as `config-1.x-backup.yml`. Upgraded servers keep showing their `nametag-format` above heads (now with
  full colours) and start with the tab header/footer and join/quit messages disabled.
- `nametag-format` now sets the tab-list name (and the head nametag only with `nametags.style: team`).
- `/lpcf` without arguments shows help; `lpcf.admin` grants every admin command.
- Spigot/Bukkit are no longer listed: LPCF has always needed Paper's chat API.

## Install

Replace `LuckPermsChatFormatterFolia-1.2.x.jar` with `LPCF-2.0.0.jar` and restart. Requires LuckPerms;
PlaceholderAPI is optional.
